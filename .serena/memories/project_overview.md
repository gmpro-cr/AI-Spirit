# Esperit.AI - Project Overview

## Purpose
Esperit.AI is a conversational AI platform that enables users to engage with AI-driven personas - from business icons to historical figures, celebrities to fictional characters.

## Key Features
- 10+ pre-built personas across 5 categories (Business Leaders, Bollywood Stars, Historical Figures, etc.)
- Text-based chat with natural language AI powered by Google Gemini 1.5 Flash
- Google OAuth + Email/Password authentication
- Guest mode with 10 messages/chat limit
- Multilingual support (English, Hindi, Hinglish)
- Content moderation with multiple safety layers
- Dark theme with glassmorphism design

## Tech Stack
- **Frontend + Backend**: Next.js 14 (Pages Router)
- **Database + Auth**: Supabase (PostgreSQL)
- **AI Model**: Google Gemini 1.5 Flash
- **Styling**: Tailwind CSS
- **Deployment**: Vercel
- **Testing**: Python + Playwright
