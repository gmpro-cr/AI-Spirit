## Technical Implementation Notes

### System Prompt Quality

Each new persona needs:
1. **Detailed Background** (200-500 words)
   - Life story, achievements, historical context
   - Personality traits, communication style
   - Famous quotes, philosophies

2. **Language Rules** (Critical!)
   - Match user's language
   - Appropriate length based on question
   - Character-specific tone and vocabulary

3. **Conversation Starters** (4-6 examples)
   - Career advice
   - Personal struggles
   - Success stories
   - Philosophical questions

4. **Safety Guidelines**
   - No financial/medical/legal advice
   - Handle inappropriate questions
   - Stay in character while prioritizing safety

### Avatar/Image Requirements

- High-quality images (512x512 minimum)
- Copyright-free or licensed
- Diverse, professional representation
- Consistent style across personas

## Risk Mitigation

### Copyright/Likeness Rights

**Risk**: Using real people's names/likenesses without permission

**Mitigation**:
1. Add clear disclaimers: "AI simulation for entertainment/education"
2. Focus on deceased figures (public domain)
3. For living persons:
   - Use only factual, public information
   - Avoid endorsements or false statements
   - Include "parody/educational use" clause
4. Consult legal counsel for high-risk personas

### Content Moderation

**Risk**: Personas generating inappropriate content

**Mitigation**:
1. Strengthen system prompts with safety rules
2. Monitor flagged conversations
3. User reporting system (already implemented)
4. Regular audits of persona outputs
5. Blacklist certain topics per persona

### API Cost Explosion

**Risk**: Too many Gemini personas = high costs

**Mitigation**:
1. **Smart routing**: Route users to Groq personas when possible
2. **Suggest alternatives**: "Kohli is busy, try Sachin?"
3. **Response caching**: Cache common questions per persona
4. **Guest limits**: 5 messages for guests, then sign up
5. **Premium tier**: Unlimited access = $5/month
